### 🧠 Kryton

[**Kryton**](https://github.com/azrtydxb/kryton) is our flagship product: a shared brain for people and AI. A self-hosted knowledge base with a built-in MCP server, wiki-linking, graph visualization, and mobile sync. ([desktop](https://github.com/azrtydxb/kryton-desktop) · [plugins](https://github.com/azrtydxb/kryton-plugins))

### 🤖 AI tooling

| Project | What it is |
|---|---|
| [**procoder**](https://github.com/azrtydxb/procoder) | Senior-developer discipline for AI coding agents: a commit gate, quality controllers, and a lessons loop. |
| [**novamem**](https://github.com/azrtydxb/novamem) | Tiered memory service for AI agents over HTTP and MCP, with synaptic decay and hybrid search. |
| [**Fastllm-proxy**](https://github.com/azrtydxb/Fastllm-proxy) | The lowest-overhead LLM router: one OpenAI-compatible endpoint in front of 80 providers. |
| [**go-ai-sdk**](https://github.com/azrtydxb/go-ai-sdk) | An idiomatic Go port of the Vercel AI SDK across 39 providers. |
| [**Promptforge**](https://github.com/azrtydxb/Promptforge) | Manage, share, and organize AI prompts. |
| [**dhole**](https://github.com/azrtydxb/dhole) | Durable, typed workflows editable by humans and agents alike. *Design phase.* |
| [**ha-local-llm-conversation**](https://github.com/azrtydxb/ha-local-llm-conversation) | Home Assistant conversation agent for any OpenAI-compatible endpoint. |

### ☸️ Platform engineering

| Project | What it is |
|---|---|
| [**novanet**](https://github.com/azrtydxb/novanet) | eBPF-based Kubernetes CNI with identity-based policy and native BGP/OSPF/BFD routing. |
| [**NovaRoute**](https://github.com/azrtydxb/NovaRoute) | FRR-based routing control plane for Kubernetes, managed over gRPC. |
| [**novaedge**](https://github.com/azrtydxb/novaedge) | Load balancer, reverse proxy, VIP controller, and SD-WAN gateway in one. |
| [**novastor**](https://github.com/azrtydxb/novastor) | Block, file, and object storage on a single chunk engine, with no etcd and no Ceph. |
| [**NovaNas**](https://github.com/azrtydxb/NovaNas) | Storage control plane for a ZFS-based NAS appliance. ([packages](https://github.com/azrtydxb/NovaNas-packages)) |
| [**planmyrack**](https://github.com/azrtydxb/planmyrack) | Plan a 19" or 10" server rack on web, iOS, and Android. |
